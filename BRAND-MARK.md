# The Corder mark: which file, where, and why

Read this before putting the logo on any surface. There are TWO legitimate
versions of the mark and one file that must never be used again; picking the
wrong one is the single most common brand mistake on this project.

Last verified: 2026-07-17.

## The two versions

| Version | File | Where it belongs |
|---|---|---|
| **3D** (gradients, lit capsules, soft inner shadow) | `assets/corder-mark-3d-2048.png` | **Everything on the web**: this landing, share.getcorder.com, emails, social cards, decks |
| **Flat** (white squircle, two solid `#111` capsules, no shadow, no gradients) | `/Users/3mpq/corder-brand/corder-mark.svg` | **macOS surfaces only**: Dock / Finder / cmd-tab icon, DMG background |

They are not interchangeable, and the split is deliberate:

- **macOS draws its own shadow** under a Dock icon. Ship it a mark that already
  has baked-in depth and it gets shadow twice — that's why the app icon is flat.
  Verified 2026-07-17: the icon inside both `Corder.app` and
  `/Applications/Corder.app` is the flat one. The Dock *looks* three-
  dimensional because of the shadow macOS adds, not because the file is 3D.
- **The web draws nothing.** A flat white squircle on a white page is invisible,
  so every web surface uses the 3D render, which carries its own depth.

So "make it look like the Dock icon" and "use the 3D render" are the same
instruction, arrived at from opposite directions.

## Never use `brand-mark-128.png`

`public/brand-mark-128.png` is 128×128 **crushed to 2 KB**. On an image that is
entirely gradients, soft shadows and a lit edge, that compression reads as
mush — and at any size above ~42px on a 2x screen it doesn't even have the
pixels. It was the cause of a "why is the logo so soft" report on 2026-07-17.

It is still referenced by `src/components/sections/Nav.tsx` (rendered at 32px,
so 64 real pixels on 2x — the file barely covers it and the compression shows).
**Re-cut it from the 2048 source.** For reference, share.getcorder.com now
ships `brand-mark-256.png` at 18 KB, which covers 56px even at 3x.

## Cutting a new size

Always resample from `assets/corder-mark-3d-2048.png`. Never from an already
rendered small PNG, and never from the flat SVG (that's a different mark).

```bash
cp assets/corder-mark-3d-2048.png public/brand-mark-256.png
sips -Z 256 public/brand-mark-256.png
```

Rule of thumb: the file needs **3× the CSS size** to survive a 3x screen. A
32px mark wants 96+; a 56px mark wants 168+. Round up to the next power of two
and don't compress below ~15 KB at 256 — the gradients are the whole point of
this version.

## Where the mark currently lives

- `assets/corder-mark-3d-2048.png` — the 3D source. Everything web comes
  from here.
- `public/brand-mark-128.png` — **pre-crushed, do not use**, re-cut it.
- `public/icon.svg`, `favicon-32/16.png`, `apple-icon.png`, `icon-192/512.png`
  — generated by `scripts/generate-seo-assets.mjs` from the 3D source. These
  are fine.
- `/Users/3mpq/corder-brand/` — the flat mark, its geometry, and the
  regeneration script. Source of truth for macOS surfaces.
- `/Users/3mpq/Corder/Resources/icons/AppIcon.{svg,icns,iconset}` — the Dock
  icon, built from the flat mark.
- `/Users/3mpq/Corder/Web/public/brand-mark-256.png` — the share page's copy,
  cut from the 3D source.
